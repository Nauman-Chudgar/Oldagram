## Oldagram

Oldagram is a small Instagram-inspired photo feed project. It recreates the familiar social feed experience with a vintage-themed name and presentation.


## Features

- Browse a feed of photo posts
- View each post’s author, caption, and likes
- Like posts
- Responsive layout for desktop


## Getting started

Clone or download this project, then open index.html in a web browser. If the project uses a development server, follow the run instructions for its framework or package manager.
